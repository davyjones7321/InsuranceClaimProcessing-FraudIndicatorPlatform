# Decision Register

This register records all business, architectural, and policy decisions approved for the Insurance Claim Processing & Fraud Indicator Platform (v1).

Status definitions:
- **DECIDED**: Approved by owner on 2026-11-20. Implement it.
- **DECIDED (default, revisable)**: Owner delegated choice and best-approach default is approved. Implement it. Changes are handled as change requests, not defects.
- **PROVISIONAL**: Approved for now; stated condition must be met before production acceptance.
- **OPEN**: Not decided. Dependent behavior is NOT implemented until owner records approval.
